# Existing Harness read access

Historical0.2.0-preview.1 read-surface design. Its no-write boundary applies to the six persisted-read tools; the current native workspace task path is separate and documented in [native-execution-usage.md](native-execution-usage.md).

Date: 2026-10-19. The owner explicitly requested that the personal Dot can read the existing DeepSeek Harness broadly, superseding the earlier fixture-only restriction for this new read surface. The authorized scope is the owner's Harness workspaces, session history and normal project/context material. It does not authorize writes, prompt submission into existing sessions, arbitrary RPC forwarding, credential export or native WeChat UI access.

Version0.2.0-preview.1 keeps the existing five task tools and isolated31470 task host. Six named harness_* read tools use an independent authenticated31471 reader. The MCP process routes only those exact names to that reader; target URLs/RPC methods/headers are never supplied by tool callers. The reader reads existing persisted storage using public format codecs, not live Desktop RPC activation paths. No resume/load/repair/prompt methods run. Existing Desktop agents and sibling plugins are never restarted, awakened or modified.

Directories and text files are scoped to persisted workspaces plus trusted operator-configured extraWorkspaces for ordinary context. Global instructions roots expose only AGENTS.md; canonical real skill directories may be registered after local symlink resolution, without runtime symlink traversal. Credential files, environment/account stores, cookies and tokens are excluded; free-text output uses best-effort secret-pattern redaction before pagination. Reads are bounded with explicit continuation. Persisted snapshots exclude live memory and do not claim the effective model context. No private material is automatically forwarded to the separate DSH model host.

Verification started with synthetic storage/filesystem fixtures, including rejected mutating names and secret-leakage tests. The main thread then confirmed local existing-data probes and actual Dot workspace/session pagination, persisted text and instruction/skill/project-file sample reads, with matching file hashes. Public proof excludes private names, identifiers and bodies; coverage is a bounded sample rather than exhaustive history validation.
