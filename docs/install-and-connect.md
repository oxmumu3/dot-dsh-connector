# 安装并连接自己的 Dot

当前版本为 `0.6.0-preview.18`（预发布版）。本版修复 Harness 0.2.1-rc.3 更新后不能加载、预检和读取会话的问题；采用原生加载、纯会话读取和合成原生任务验收。此前 preview.17 的真人 Dot 验证保留在历史记录，本轮不扩大为新的云端账号或手机验收。当前支持 macOS，并要求账号具备相应官方权限；实测范围见[验收记录](verification.md)。

这个插件让你的 Dot 读取 DeepSeek Harness 项目并派任务。连接使用你自己的账号和电脑，任务使用 Harness 原有的模型、工具和审批设置。

## 一句话安装

在 Harness 新建会话，选择「创造模式」，粘贴：

> 请使用插件管理工具安装并启用这个 Dot → Harness 插件：https://github.com/oxmumu3/dot-dsh-connector/releases/download/v0.6.0-preview.18/dot-dsh-management-0.6.0-preview.18.tgz 。保留已有连接、配置和任务。安装成功后告诉我打开侧栏「Dot 连接」；首次使用点击「连接我的 Dot」，按提示登录自己的账号并确认授权，原有连接继续沿用。

如提示安装审批，核对后确认。只安装 `dot-dsh-management` 这一个原生插件即可；不需要另装仓库根包、运行终端命令或创建 DeepSeek 模型 API key。

## 第一次连接

打开侧栏「Dot 连接」，点击「连接我的 Dot」。插件准备本机服务并打开官方连接窗口，接下来按页面提示完成：

- **登录自己的账号。** 使用插件打开的 Ego 浏览器登录。没有 Ego 时，先点「安装 Ego 并继续」，完成首次浏览器设置后回到 Harness 继续；不要求导入其他浏览器数据。
- **选择账号范围。** 核对自己的组织与 ChatGPT 工作区。插件自动填写支持的连接配置。
- **确认授权。** 在官方页面确认通道、专用连接密钥和个人工具连接。每次完成后回到 Harness 点击「继续连接」。看到「Save your key／保存密钥」时先保留窗口，不要点 Done；插件会自动保存密钥，无需复制或转交。
- **等待实际验证。** 插件让真实 Dot 读取项目并派发一个验证任务。需要回答或审批时，从提示打开对应 Harness 会话处理。验证完成后，页面显示连接结果。

如 Harness 还没有项目，按提示选择一个你允许操作的文件夹。只读的 memory、skills、instructions 目录不能作为任务项目。

这些是主要环节，不是固定点击次数：首次浏览器设置、验证码、额外授权和 Harness 审批都可能增加操作。官方权限确认保留给本人；系统负责配置、密钥传递和验证。

## 让 Dot 开始工作

连接完成后，直接对自己的 Dot 说：

> 找到我在 Harness 里的目标项目，先列出文件并阅读项目说明。给 Harness 派一个任务，完成我要求的修改并运行验证。把任务编号、改动和结果告诉我。

不要求项目公开。Dot 可以让 Harness 修改文件和运行命令；审批规则与平时使用 Harness 一致。任务被受理只代表开始处理，实际完成后再查看结果。

## 跟进、恢复与续期

- **继续任务：** 让 Dot 找到原任务，再说明新要求；也可从任务页接续。
- **等待回答或审批：** 打开提示中的 Harness 会话处理。插件不会自动批准。
- **任务超时或状态未知：** 按原任务编号查询，不要换一个请求重派相同写操作。
- **取消或整理：** 可以取消连接创建的任务，或归档已结束任务；已经完成的文件修改和命令不会自动撤销。
- **授权快到期：** 提前 7 天提醒后点击「更新连接授权」。插件沿用原通道、个人插件和任务记录，自动填写新授权；你确认后自动保存、验证并切换。验证失败时保留原密钥。旧版未记录的期限显示待确认，不猜日期。
- **误关密钥保存窗口：** 按提示点「重新创建授权」，继续官方确认；不用请作者改配置。
- **连接窗口已被删除：** 点「重新打开连接窗口」。只有确认旧窗口不存在时才创建替代窗口；网络超时留在原窗口重试。
- **Harness 重开后等待首次调用：** 若页面显示通道已启动、等待首次调用，可直接让 Dot 读取或派任务。接入暂停时先恢复；状态读取失败时按提示核实，不把旧验证时间当作当前在线。

Harness 必须保持运行；关闭插件页面不影响后台连接。应用退出后，已交给 Harness 的工作按实际会话状态核对，不自动重派不确定的写任务。

## 使用前确认

当前支持 macOS 的 Harness Desktop，已核对宿主基线为 `0.2.1-rc.2` 或 `0.2.1-rc.3`；标准原生安装不需要另装全局 Node 或 Python。你需要具备 Dot、Tunnel、自定义工具权限的 OpenAI 账号，以及 Harness 中可用的模型、工具和真实项目。账号资格由官方决定。

升级同一个插件会沿用原有连接与数据。使用外部服务的旧部署，先按[维护说明](operator-runbook.md)核对归属及运行中的任务，不删除旧凭据或关闭未知服务。

版本、实际验证范围和仍未覆盖的环境见[验收记录](verification.md)。详细首次连接机制见[首次连接说明](first-connection.md)；[手动配置参考](new-user-connect.md)仅用于旧部署，不是普通用户的主流程。
