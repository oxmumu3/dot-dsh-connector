# 安装并连接 Dot

这是一个 DeepSeek Harness 原生插件。用户安装的包是 `dot-dsh-management`；`dot-dsh-connector` 是开发与 MCP 配套源码包，不需要再作为第二个 Harness 插件安装。

## 安装一句话

在 Harness 新建会话，选择「创造模式」，粘贴下面一句话。它会通过官方插件管理工具下载并安装；如提示安装审批，核对后确认。

> 请使用插件管理工具安装并启用这个 Dot → Harness 插件：https://github.com/oxmumu3/dot-dsh-connector/releases/download/v0.6.0-preview.13/dot-dsh-management-0.6.0-preview.13.tgz 。保留已有连接、配置和任务。安装成功后告诉我打开侧栏「Dot 连接」；首次使用点击「连接我的 Dot」，按提示登录自己的账号并确认授权，原有连接继续沿用。

首次安装后打开侧栏入口并点击连接；升级时继续使用原有连接。这里是已通过匿名下载核验的 preview.13 固定地址，官方一句话安装已实际应用，56 个文件与发布包、源码一致。preview.14 为修复候选，尚待公开发布、安装与实机验收。

这句话是给 Harness 的安装指令；本人仍需完成账号登录和平台要求的授权。正式仓库为 [oxmumu3/dot-dsh-connector](https://github.com/oxmumu3/dot-dsh-connector)。源码快照不等于发布回执，下载资产可用性以固定版本发行页为准。

## 第一次使用

从插件内点击「连接我的 Dot」。本机没有 Ego 时，点击「安装 Ego 并继续」，插件自动下载、验证官方签名并安装；完成 Ego 首次设置后回到这里继续，不要求导入浏览器数据。它自动准备本机服务，在同一个 ego 工作空间中接续官方页面和支持自动填写的账号设置。你在官方页面登录自己的账号，确认目标组织 / ChatGPT workspace 与最终授权；随后插件自动验证实际读取和原生任务。无需自己复制密钥、通道编号或终端命令。

官方确认完成后，回到 Harness 点击「继续连接」。创建密钥后，先保留「Save your key／保存密钥」窗口，不要点 Done；插件自动保存成功后再关闭，无需手动复制。按两个站点都需登录计算为 6 个人工环节；ego 内两处都已登录时为 4 个。环节不等于点击次数；没有 Ego 时另有安装确认与首次设置，验证码或额外授权也可能增加操作。

此前 `0.6.0-preview.12` 已通过 Harness 官方界面安装并启用，54 个安装文件与源码及归档一致。该版本安装后的 provider 与 worker 已通过真实 Dot 验收：新鲜项目读取、恰好一个原生任务及精确关联的完成回执，管理页自动从等待首次调用转为云端在线。此前 preview.9 已完成新通道、密钥和个人插件的创建与授权；本轮本人也完成了 Ego 中的 Google 官方交互登录。这些不是空白浏览器或全新账号资格测试，不能承诺任意账号都具备 Dot、Tunnel 和自定义工具权限。

缺少 Ego 的安装分支已通过 31/31 回归及真实隔离安装实测：安装包校验、复制、签名与系统安全检查均真实执行，仅最后打开应用被拦截，现有 Ego 未改动。GUI 首次设置与完全空白机器仍未验收。

详细说明见 [首次连接](first-connection.md)。旧版五步配置保留在 [手动连接参考](new-user-connect.md)，不作为新版主流程。

可复制给 Dot 的首次任务示例：

> 找到我在 Harness 里的目标项目。先读 README，告诉我项目做什么，再新建 Harness 任务，在该项目的临时验证目录写一份简短说明并读回校验。把项目名、任务编号和结果告诉我。

选择自己允许写入的项目即可，不要求项目公开。真实任务可以修改文件、运行命令，执行权限与审批继续由 Harness 的正常设置决定。

## 日常使用

- 想接着做：让 Dot 找到最近那项任务，再说明新增要求。任务页也提供接续入口。
- 想知道进度：查看任务状态和最近活动。需要回答或审批时，打开对应 Harness 会话处理。
- 想结束任务：取消连接创建的任务；已执行的命令和已写入的文件不会自动撤销。
- 想整理记录：归档已结束任务；归档保留请求身份和记录，不等于删除任务或项目文件。
- 想暂停接入：停止新的读取和派活；正在运行的任务继续执行，任务查询和取消仍可使用。

Harness 需要保持运行。关闭「Dot 连接」页面不影响后台执行；退出应用会停止由插件托管的连接服务，已交给 Harness 的工作需按实际会话状态核对，不能盲目重派。

preview.11 已通过插件冷启动恢复实测：插件恢复原通道后显示「通道已启动 · 等待首次调用」，此时可直接向 Dot 派任务，无需重新登录或再次验证。真实项目读取成功后，管理页自动更新为云端在线、连接已恢复，上次完整验证日期保留。这次未派发新验证任务，也未重新打开浏览器；实测范围是插件冷启动，未覆盖整机重启。此前 preview.12 另已验证真实调用后自动转为云端在线。preview.13 已安装，新一轮真实 Dot 任务仍在核对，尚无新的完成回执。接入已暂停时先恢复接入；状态读取失败时先按提示刷新核实。

## 已经安装旧版

升级同一个 `dot-dsh-management` 插件，保留原有账号连接与数据。使用外部服务的旧部署仍可继续采用已有配置，不能把旧凭据、账本或云端连接当作垃圾删除。切换到插件托管服务前，先核对旧服务归属、正在运行的任务和端口占用。

当前机器上的实际升级与验收状态以 [verification.md](verification.md) 和版本交付记录为准。安装成功、本机就绪、Dot 接通、任务内容合格是不同状态。

旧后台服务会进入明确的兼容模式：保留原有状态、任务列表、查询、取消和 worker 通路，隐藏它不支持的新版筛选、归档及页面接续。更新后台服务后才启用这些增强；不会通过失败重试猜测权限，也不会在升级插件时擅自重启外部服务。

## 遇到问题

preview.13 已安装并包含以下恢复入口。真实「更新连接授权」操作遇到 Ego 执行兼容问题，旧密钥与原通道保留；preview.14 源码已修复这一问题，尚待安装后验证，不将自助续期写成已实机通过。具体范围见 [验收记录](verification.md)：

- **连接授权快到期：** 页面提前 7 天提醒，点击「更新连接授权」。插件复用原来的通道与个人插件，自动填好官方密钥表单；本人确认后自动保存、验证并切换。旧版未记录的期限显示「到期时间待确认」，不猜日期。
- **创建密钥后误关保存窗口：** 按提示点「重新创建授权」。当前连接与旧密钥保留，不需要作者替你改配置。
- **原连接窗口已被删除：** 点「重新打开连接窗口」。只有核实旧窗口不存在后才建立替代窗口；普通网络超时仍留在原窗口重试。
- **Harness 异常退出：** 再次启动时自动恢复已启用连接，仅回收能确认已退出的自有实例留下的锁。正在运行或归属不明的实例继续受保护；不会自动重派写任务。

- **本机检查未通过：** 按具体检查项处理；当前运行环境支持范围以插件诊断结果为准。
- **端口被占用：** 先核对是否已有旧部署，不能关闭未知服务或抢占其端口。
- **本机就绪，但 Dot 找不到工具：** 检查账号侧连接及工具目录；本地在线不代表账号连接已经配置。
- **读取暂时失败：** 页面保留最后成功状态并标记时间；可重试对应列表，无需重复派任务。
- **任务状态待核实：** 使用原任务编号查询和核对会话；不要换请求编号重派同一项写操作。
- **更新提示需要重启：** 先保留正在运行的工作，待合适时机按宿主提示完成；不能为了更新这个插件重载其他工作。
