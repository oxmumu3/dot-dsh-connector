# 首次连接流程模拟

[打开交互模拟](index.html)

当前模拟对应 `0.6.0-preview.12`（2026-10-23），新增缺少 Ego 时的安装确认与本人首次设置分支。原生插件已安装启用，安装后的真实 Dot 读取与派任务验收已通过；Ego 安装路径另通过真实隔离实测。GUI 首次设置与完全空白机器仍未验收。下方 preview.1 源码行号及浏览器走查保留为历史记录。

这是对当前流程的拆解。HTML 单文件可离线打开，不依赖远程字体、脚本或图片；不收集账号、安装应用、调用服务、创建密钥或派发真实任务。官方页面使用简化示意。preview.12 已通过安装后的真实读取与派任务；本轮本人另完成了 Ego 中的 Google 交互登录。模拟结果不代表浏览者自己的账号已经连接。

## 实际需要多少步

从**已安装插件、Harness 已登录并至少有一个登记项目、Ego 已就绪**开始，两个站点均要求登录时，默认按 **6 个人工环节**展示。本机未安装 Ego 时，展开对应分支，增加安装确认和本人首次设置两个环节，共 **8 个**。这里的“环节”是一次需要用户处理的页面任务，并非点击次数。

| 人工环节 | 用户实际做什么 | 自动化部分 |
| --- | --- | --- |
| 1. 点击开始 | 在「Dot 连接」点「连接我的 Dot」 | 检查环境、准备服务、下载组件、打开 ego 连接页面 |
| 2. 登录 OpenAI | 在官方页面登录；有验证码时完成验证 | 直接打开通道设置入口 |
| 3. 选择工作区并创建 | 核对当前组织，选择自己的 ChatGPT 工作区，确认创建通道后回 Harness 继续 | 填名称与说明，读取创建结果；无需复制通道编号 |
| 4. 确认运行权限 | 核对权限并创建专用密钥；保留保存密钥窗口，回到 Harness 继续；多个项目时选项目 | 单项目自动选定；填写 Tunnels Read/Use、其他权限 None、30 天有效期；自动保存刚创建的密钥 |
| 5. 登录 ChatGPT | 如未识别登录，登录工作区对应账号 | 直接打开插件页面；登录有效时跳过 |
| 6. 确认创建个人插件 | 核对连接、勾选官方风险提示、点击「创建为插件」，完成官方授权后回 Harness 继续 | 填名称、说明、通道编号和连接方式，检查已关联回执 |

随后自动发送自检请求，让 Dot 列出项目并派发标记任务，查询结果，核对通道健康和同一请求的实际完成回执。普通等待不计入人工环节。

缺少 Ego 的分支放在检查本机之后、官方账号登录之前：先点击「安装 Ego 并继续」，插件执行下载、签名校验和安装；然后本人完成 Ego 首次设置，回 Harness 点击「我已完成，继续连接」。无需导入其他浏览器的数据。下载等待页是自动过程，不另计人工环节；实际系统提示可能增加操作。

**密钥无需复制粘贴。** 插件自动填写创建表单，用户核对后确认创建；插件随后读取这次刚创建的专用密钥，保存到本机并用于连接配置。用户需要处理的是登录、工作区/必要项目选择和最终确认，不需要手工搬运密钥、通道编号或运行命令。因而可以跟着页面向前走，但不能把登录与选工作区也概括为盲点“OK”。

### 登录与条件分支

- Ego 已就绪、两处都需要登录：6 个人工环节。ChatGPT 自动识别登录可少一个；两处登录都有效则为 4 个。
- 本机未装 Ego：展开默认关闭的条件分支，另加安装确认和本人首次设置两个环节。下载过程自动完成，不计为人工环节。是否能免登仍由官方页面决定。
- “已登录”必须是插件使用的**ego 官方页面**内登录有效，不等于其他浏览器已登录。新安装不能默认免登。
- 创建个人插件后若出现独立连接授权页：模拟中另加一个人工环节；不能宣称所有账号都必经此页。
- 自检触发 Dot 或 Harness 工具审批：模拟中另加一个合并环节。真实审批可能不止一次，代码不会替用户批准。
- 多项目选择放在密钥确认页内，所以不加环节数，但会增加操作。多组织切换、验证码、注册、条款、组织管理员授权等取决于账号。
- 插件安装、账号注册、开通原本没有的组织/工作区权限不计入本模拟，遇到权限限制不能保证直接走通。

因此，“本机准备 → 登录与授权 → 验证连接”的 **3 个阶段不等于 3 次操作**；也不能把自动填表描述为“一次授权就连好”。

## 首次连接之后

成功配置且未暂停连接时，插件再次启动会恢复原通道。看到「通道已启动 · 等待首次调用」，可以直接给 Dot 派任务，无需重新登录、授权或再跑验证；真实调用后会自动核实云端状态。等待态不会提前显示为云端在线，上次完整验证日期单独保留。接入已暂停时先恢复接入；读取状态失败时，按实际提示刷新核实。

## 模拟使用

1. 打开 `index.html`，在页面里点击蓝色主按钮逐页前进。
2. 工作区、项目或风险确认项需要实际选择后，模拟按钮才启用。
3. 左侧导航可直接查看任一画面；“上一页”和“重新体验”用于复查。
4. 顶部可切换两处登录是否有效；下方可打开缺少 Ego、多项目、独立连接授权与工具审批分支。场景改变会重置模拟，人工环节数同步变化。

演示专用的“模拟完成登录”“模拟自动完成”等按钮，不是已安装插件中的按钮。正式插件依据官方页面状态和真实回执自动继续。
