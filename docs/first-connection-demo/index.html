    插件界面的“本机准备 → 登录与授权 → 验证连接”是阶段概览。中间的登录与授权展开后，会经过多个官方页面。本模拟把它们拆开计算。

    计数范围：插件已安装、Harness 已登录且有可用项目。下载与安装 Harness 插件不在计数内；缺少 Ego 的准备可在上方展开，另加两个环节。
